# ✈️ 旅遊分帳小幫手

> 多人旅遊費用分攤計算機，一鍵算清誰欠誰多少錢！

🌐 **線上體驗：[s11314180.github.io/Splitter](https://s11314180.github.io/Splitter/)**

---

## 📖 簡介

出去旅遊最麻煩的事，就是事後算帳！  
**旅遊分帳小幫手**是一款純前端網頁工具，不需要登入、不需要安裝，打開網頁就能用。  
支援多人消費紀錄、自動計算每個人的收支差額，並透過**最小化轉帳次數演算法**，算出最省事的還錢方式，結果還能一鍵複製貼到 LINE 群組！

---

## ✨ 功能特色

### 👥 旅伴成員管理
- 快速新增／刪除旅伴成員
- 以 Chip 標籤形式顯示，一目了然
- 刪除有關聯帳目的成員時，自動提示並清理

### 💳 消費明細記錄
- 記錄消費項目名稱、金額、付款人（代墊者）
- 彈性勾選「哪些人要分攤這筆費用」
- 支援一鍵全選／取消全選
- 消費列表顯示每人應分攤金額，支援單筆刪除

### 🧮 智能結算
- 即時計算每位成員的**總代墊金額**、**應分攤總額**、**淨收支差額**
- **最小化轉帳次數演算法**：自動配對債權人與債務人，產生最精簡的轉帳清單
- 一鍵複製結算結果，格式化純文字，可直接貼到 LINE 群組

### 💾 資料不遺失
- 所有資料自動儲存於瀏覽器 `localStorage`
- 重新整理頁面後資料依然保留
- 提供「清空所有資料」重設按鈕（二次確認保護）

## 🚀 使用方式

1. 開啟網頁：[s11314180.github.io/Splitter](https://s11314180.github.io/Splitter/)
2. 在「**成員管理**」頁籤新增所有旅伴姓名
3. 在「**消費明細**」頁籤逐筆輸入旅途中的花費
4. 切換到「**智能結算**」查看結果，按下「一鍵複製」貼給大家

> 💡 第一次開啟網頁時，會自動載入範例資料（小明、小華、美美），方便快速了解操作流程。

## 📐 結算演算法說明

採用**貪婪配對演算法**：

1. 計算每人的「淨額」= 總代墊金額 − 總應分攤金額
2. 將淨額為正（應收錢）的人列為**債權人**，淨額為負（應付錢）的人列為**債務人**
3. 每次配對金額最大的債權人與債務人，產生一筆轉帳，重複直到所有帳目結清
4. 此方法可在大多數情境下達到**最少轉帳筆數**

**範例：**
```
小明代墊 NT$1,800（晚餐，三人均分）→ 淨額 +1,200（應收）
小華付了 NT$0                       → 淨額 -1,050（應付）
美美代墊 NT$900（門票，兩人均分）   → 淨額  -150（應付）

建議轉帳（僅需 2 筆）：
  小華 → 小明：NT$1,050
  美美 → 小明：NT$150
```
